# Legacy Research Archive (Phase 1 – Phase 6)

Thư mục lưu trữ toàn bộ mã nguồn, tài liệu, logs và script sinh notebook thuộc các giai đoạn nghiên cứu trước đây (Phase 1 đến Phase 6: nghiên cứu feedback trap, STE, analysis gradient flow, negative-result manuscript, các notebook phụ trợ và các file tạm):

## Danh mục nội dung lưu trữ
- `analysis/`: Các script phân tích gradient flow, feedback analysis, và chẩn đoán feedback trap offline (Phase 1–6).
- `diagnostics_output/`: Kết quả logs, biểu đồ drift BatchNorm và saturation chẩn đoán Phase 6.
- `papers/`: Bản thảo Overleaf cũ (12 trang IEEEtran về feedback trap và negative-result).
- `fanet-benchmark-dsb2018/`, `benchmark_notebooks/`: Các notebook benchmark giai đoạn đầu.
- `kaggle_logs/`, `kaggle_logs_cvc/`, `kaggle_output/`, `kaggle_output_v7/`, `kaggle_dsb_upload/`: Logs và outputs Kaggle lịch sử.
- `scratch_fanet/`, `scratch_test_nuclei/`, `scratch_test_single/`: Thư mục scratch thử nghiệm đơn lẻ.
- `generate_*.py`, `patch_*.py`, `fix_script*.py`, `rebuild_all_notebooks.py`, `update_*.py`: Các script sinh file hàng loạt ở thư mục gốc cũ.
- `bgdnet_extracted.txt`, `bgdnet_paper.pdf`, `stage1_train.zip`: Tài liệu tham khảo và file nén tạm.
